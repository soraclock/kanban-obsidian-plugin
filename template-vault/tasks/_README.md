# 個人カンバンタスクボード

1 タスク = 1 Markdown ファイル。frontmatter にステータス・優先度などを記録し、本文に背景・次のアクション・メモを書きます。

---

## ID 採番

- 形式: `K-NNNN`（K = Kanban、4 桁ゼロ埋め連番）
- ファイル名: `K-NNNN-{slug}.md` 例: `K-0001-read-three-books.md`
- 次のID: **K-0004**

新規作成時、プラグインの「+ 新規タスク」ボタン or コマンドパレットから採番されます。手動で作る場合はこのファイルの「次のID」を +1 して書き戻してください。

---

## frontmatter スキーマ

```yaml
---
id: K-0001
title: タスクのタイトル（簡潔に）
status: 未着手           # 未着手 | 進行中 | 確認待ち | 完了 | 凍結
assignee: 自分           # 自由記入（例: 自分 / 家族 / 同僚名）
priority: P1             # P0 | P1 | P2 | P3
due: 2026-05-15          # ISO date (YYYY-MM-DD)。期限なしは省略
created: 2026-05-10
updated: 2026-05-10
tags: [tag1, tag2]
related: []              # Obsidian リンクの配列。任意
completedAt: null        # 完了日 (status=完了 にしたとき手動で記録)。任意
estimateHours: null      # 見積時間 (h)。任意
actualHours: null        # 実績時間 (h)。任意
recurrence: null         # 定期タスク。null or daily / weekly:mon / monthly:15 / monthly:lastday / every:7d
---
```

本文の規定セクション:

```markdown
## 背景
（なぜこのタスクが必要か、文脈）

## 次のアクション
- [ ] チェックボックスで列挙

## メモ
（自由）
```

---

## 列の定義

| 列 | 意味 |
|----|------|
| **未着手** | まだ何も手を付けていない |
| **進行中** | 今アクティブに進めている |
| **確認待ち** | 自分の手は離れて他者・自分の確認待ち |
| **完了** | 終わった（タブ切替で表示） |
| **凍結** | 当面手を付けない（タブ切替で表示） |

## 優先度

| ラベル | 意味 |
|--------|------|
| P0 | 今すぐ着手・完了 |
| P1 | 今週中に前進 |
| P2 | 月内に処理 |
| P3 | 今期内に対応 |

---

## アーカイブ

完了タスクを残し続けたくない場合、詳細ペインの「アーカイブ」ボタンで `_archive/YYYY-MM/K-NNNN-slug.md` に退避できます。アーカイブビューから復元も可能です。
